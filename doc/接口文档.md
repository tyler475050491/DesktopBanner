# DesktopBanner 接口文档

版本 1.0.0 · 模块 `DesktopBanner.dll` · 头文件 `src\DesktopBanner.h`

---

## 1. 调用约定

- 纯 C 接口，`__stdcall`，不涉及 C++ 对象跨 DLL 传递，因此 **C / C++ / C# / Python / Delphi** 都能直接调用。
- 全部函数都在主线程之外工作：DLL 自己创建渲染线程 + 消息泵，**宿主不需要 `GetMessage/DispatchMessage`**。
- 所有函数都可在任意线程调用，内部用互斥锁 + `PostMessage` 串行化。
- `COLORREF` 为 `0x00BBGGRR`，C/C++ 里用 `RGB(r,g,b)` 宏生成。
- 字符串均为 **UTF-16 (LPCWSTR)**；只有 `Banner_SetTextA` 收 UTF-8。

### 导出表（15 个）

```
Banner_GetVersion        Banner_GetDefaultOptions
Banner_Init              Banner_InitEx
Banner_SetStyle          Banner_SetBackground     Banner_SetTextColor
Banner_SetSpeed          Banner_SetFontSize       Banner_SetFrost
Banner_SetTextW          Banner_SetTextA
Banner_Close             Banner_IsActive          Banner_GetLastError
```

## 2. BannerOptions 结构体

`Banner_InitEx()` 用。**建议先调用 `Banner_GetDefaultOptions(&opt)` 拿到一份完整默认值再改字段**，
因为零初始化的结构体里 `bgAlpha = 0` 会导致背景完全透明（看起来像什么都没画出来）。

| 字段 | 类型 | 说明 |
|---|---|---|
| `cbSize` | `DWORD` | 必填 `sizeof(BannerOptions)`（传 0 也容忍，按当前版本解析） |
| `bgColor` | `COLORREF` | 背景色，默认 `RGB(18,20,26)` |
| `bgAlpha` | `BYTE` | 背景不透明度 0~255，默认 170；建议 120~220 |
| `textColor` | `COLORREF` | 文字颜色，默认 `RGB(96,216,255)` |
| `speed` | `int` | 滚动速度，**像素/秒**；>0 向左，<0 向右，0 静止；默认 120 |
| `fontSize` | `int` | 字体像素高度，默认 26；`<=0` 用默认 |
| `fontName` | `LPCWSTR` | 字体名，默认 `L"Microsoft YaHei UI"`；`NULL` 用默认 |
| `height` | `int` | 横幅高度（像素），默认 48；`<=0` 用默认 |
| `anchor` | `int` | 停靠位置：`0` 屏幕顶端 / `1` 屏幕底端 / `2` 工作区顶端 / `3` 工作区底端 / `4` 自定义(x,y)；默认 0 |
| `x`, `y` | `int` | `anchor == 4` 时的左上角屏幕坐标 |
| `width` | `int` | 宽度；`<=0` 表示铺满所在屏幕（或工作区） |
| `topMost` | `BOOL` | `TRUE` 始终置顶（压在其它窗口上）；`FALSE` 沉到最底层，被窗口遮挡 |
| `gap` | `int` | 两段文字之间的间隔像素；`<=0` 自动（字号×6，至少 120） |
| `frost` | `int` | 磨砂颗粒强度 0~100；0 = 纯色平涂；默认 40 |
| `reserved[4]` | `DWORD` | 保留，填 0 |

### 默认值一览

| 项 | 默认 |
|---|---|
| 背景 | `RGB(18,20,26)`，alpha 170 |
| 文字 | `RGB(96,216,255)`，微软雅黑 UI，26px |
| 速度 | 120 px/s（向左） |
| 尺寸 | 高度 48，宽度 = 主屏宽 |
| 位置 | 屏幕顶端 `(0,0)` |
| 置顶 / 磨砂 | 置顶，frost 40 |

## 3. 接口详解

### 3.1 初始化

#### `BOOL Banner_Init(COLORREF bgColor, BYTE bgAlpha, COLORREF textColor, int speed)`

最简初始化。其余参数走默认（顶端、48px、微软雅黑 26px、铺满主屏、置顶、frost 40）。
返回 `TRUE` 时横幅已经可见；`FALSE` 用 `Banner_GetLastError()` 查原因。

> 重复调用会先销毁旧横幅再重建，所以也可以用它整体切换高度/位置/置顶方式。
> 初始化**不会清空已设置的文字**（沿用当前文案；要清空请 `Banner_SetTextW(L"")`）。

#### `BOOL Banner_InitEx(const BannerOptions* options)`

完整初始化，字段见上表。`options` 为 `NULL` 或 `cbSize` 不符时返回 `FALSE`（错误码 1）。

#### `int Banner_GetDefaultOptions(BannerOptions* options)`

填一份默认值，返回 `0` 表示成功。

#### `int Banner_GetVersion(void)`

返回 `0x00010000`（主.次.修订 = 1.0.0）。

### 3.2 运行中修改样式

| 接口 | 说明 |
|---|---|
| `void Banner_SetStyle(COLORREF bg, BYTE alpha, COLORREF text, int speed)` | 一次改四项，最常用 |
| `void Banner_SetBackground(COLORREF bg, BYTE alpha)` | 只改背景色与透明度 |
| `void Banner_SetTextColor(COLORREF text)` | 只改文字颜色 |
| `void Banner_SetSpeed(int speed)` | 只改速度（px/s） |
| `void Banner_SetFontSize(int pixelHeight)` | 只改字号，会自动重新测量文字宽度 |
| `void Banner_SetFrost(int strength)` | 只改磨砂强度 0~100 |

这些接口都是**立即生效**（内部 `PostMessage` 触发一次重绘，1~2 帧内可见），窗口句柄不变，不闪屏。
在横幅未启动时调用不会报错，改动会保留到下次 `Banner_Init` 时生效。

### 3.3 修改文字

#### `BOOL Banner_SetTextW(LPCWSTR text)`

设置横幅文字。传 `L""` 则只显示背景条。**文字变更后滚动位置复位到最右侧重新开始**。
支持任意 Unicode（中文、emoji、★ 等）。

#### `BOOL Banner_SetTextA(LPCSTR utf8Text)`

同上的 UTF-8 窄字符版本；UTF-8 解析失败时自动退回本机代码页（GBK）。

### 3.4 关闭与状态

#### `void Banner_Close(void)`

销毁横幅窗口并回收渲染线程（同步等待线程退出，最长 3 秒）。可重复调用，未启动时调用无副作用。
关闭后所有 `Set*` 接口仍可用，只是修改结果会在下次初始化时生效。

#### `BOOL Banner_IsActive(void)`

横幅当前是否真的显示中。

#### `DWORD Banner_GetLastError(void)`

最近一次调用的错误码（`0` 表示成功）：

| 值 | 含义 |
|---|---|
| `0` | 成功 |
| `1` | 参数无效（空指针 / `cbSize` 不符 / 文案为空） |
| `2` | 创建工作线程失败 |
| `3` | 创建窗口或绘图缓冲失败 |
| `4` | 关闭时等待渲染线程退出超时 |
| `5` | 其它未知错误 |

## 4. 生命周期与线程规则

```
宿主线程                                  DLL 渲染线程
---------                                 --------------
Banner_Init/InitEx ──创建线程──▶          注册窗口类 → 建分层窗口 → 首帧 → SetEvent(ready)
                                      ┌──▶ WM_TIMER(16ms): 取参数快照 → 推进位移 → 合成 → UpdateLayeredWindow
Banner_SetStyle ──PostMessage(REFRESH)──▶┤ 立即重绘一帧
Banner_SetTextW ──PostMessage(REFRESH)──▶┤ 重新测量文本 + 从右侧重新滚动
Banner_Close ──PostMessage(QUIT)────────▶└─▶ DestroyWindow → 退出消息泵 → SetEvent(done)
Banner_Close 等待 done(≤3s) 后 join 线程
```

要点：

1. 只有一个渲染线程，窗口创建、绘制、销毁全在该线程，避免跨线程 `UpdateLayeredWindow`。
2. 参数用 `std::mutex` 保护，渲染线程每帧取一次快照，所以连续快速调用 `SetStyle` 不会撕裂画面。
3. `Banner_Close` 会等线程真正退出（默认 3 秒），因此可以在进程退出前安全调用；超时则 detach，不会卡死宿主。
4. 宿主直接退出而不调用 `Close` 也没问题——窗口随进程销毁，不会有残留。

## 5. 集成示例

### C++（静态链接）

```cpp
#include "DesktopBanner.h"      // 工程里定义 DB_USE_IMPORT_LIB
#pragma comment(lib, "DesktopBanner.lib")

BannerOptions opt{};
Banner_GetDefaultOptions(&opt);
opt.bgColor   = RGB(18, 20, 26);
opt.bgAlpha   = 175;
opt.textColor = RGB(96, 216, 255);
opt.speed     = 120;
opt.height    = 56;
opt.anchor    = DB_ANCHOR_WORK_TOP;   // 不压任务栏
opt.frost     = 45;

Banner_InitEx(&opt);
Banner_SetTextW(L"★ 生产环境：A 线设备 3 号告警，请及时处理 ★");
```

### C#（P/Invoke）

```csharp
using System.Runtime.InteropServices;

public static class Banner
{
    [DllImport("DesktopBanner.dll", CallingConvention = CallingConvention.StdCall)]
    public static extern bool Banner_Init(uint bgColor, byte bgAlpha, uint textColor, int speed);

    [DllImport("DesktopBanner.dll")] public static extern bool Banner_SetTextW(
        [MarshalAs(UnmanagedType.LPWStr)] string text);

    [DllImport("DesktopBanner.dll")] public static extern void Banner_SetStyle(
        uint bgColor, byte bgAlpha, uint textColor, int speed);

    [DllImport("DesktopBanner.dll")] public static extern void Banner_Close();
}

// COLORREF = 0x00BBGGRR
Banner.Banner_Init(0x001A1412u, 175, 0x00FFD860u, 120);
Banner.Banner_SetTextW("★ 桌面滚动横幅 ★");
```

### Python（ctypes）

```python
import ctypes
from ctypes import wintypes

dll = ctypes.WinDLL(r"bin\DesktopBanner.dll")
dll.Banner_Init.argtypes = [wintypes.DWORD, wintypes.BYTE, wintypes.DWORD, ctypes.c_int]
dll.Banner_Init.restype  = wintypes.BOOL
dll.Banner_SetTextW.argtypes = [wintypes.LPCWSTR]
dll.Banner_SetTextW.restype  = wintypes.BOOL
dll.Banner_Close.argtypes = []

dll.Banner_Init(0x001A1412, 175, 0x00FFD860, 120)   # RGB 是 0x00BBGGRR
dll.Banner_SetTextW("★ 桌面滚动横幅 ★")
# ... 之后调用 dll.Banner_Close()
```

## 6. 常见问题

**Q1：调用 `Banner_Init` 后什么都看不到？**
多半是 `bgAlpha` 传了 0，或者文字还没设置（默认文案会被替换为空）。先 `Banner_SetTextW(...)`，或把 alpha 调到 170。

**Q2：横幅被别的窗口盖住了？**
`topMost` 传了 `FALSE`。重新用 `Banner_InitEx` 且 `topMost = TRUE`；想"只在桌面顶部、不压别的窗口"就用 `FALSE`。

**Q3：文字有锯齿 / 发糊？**
DLL 内部已按物理像素渲染（渲染线程设了 Per-Monitor V2），不会因为宿主 DPI 感知而发糊。
若宿主自己做了缩放（如 125% 下又套了一层 DPI 虚拟化），把 `fontSize` 适当调大即可。

**Q4：怎么让横幅跟着分辨率变化？**
DLL 监听了 `WM_DISPLAYCHANGE` / `WM_SETTINGCHANGE`，分辨率或任务栏变化后会自动重算并重绘。

**Q5：多个程序同时用这个 DLL 会互相当掉吗？**
每个进程各自一份窗口，互不影响（窗口类是进程内注册的）。

**Q6：能不能让横幅响应鼠标点击（比如点一下暂停）？**
当前版本是纯穿透设计（`WS_EX_TRANSPARENT` + `WM_NCHITTEST=HTTRANSPARENT`），故意不允许交互。
需要交互的做法见 `doc/实现与二次开发说明.md` 第 9 节。
